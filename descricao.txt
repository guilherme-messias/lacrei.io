### **Gerador Personalizado de Exercícios em JavaScript**

Um programa interativo que permite aos usuários gerar exercícios personalizados em 
JavaScript com base no nível de dificuldade, na área de especialização
 (frontend, backend, full stack, ou mobile) e no tipo de desafio desejado. 
 O sistema utiliza a API da OpenAI para criar problemas adaptados às preferências do usuário, 
 apresentando-os diretamente em uma interface intuitiva e funcional.

---

### **Funcionalidades Principais:**

1. **Filtro de Nível de Dificuldade:**  
   - **Opções:** Iniciante, Intermediário, Avançado.  
   - O sistema ajusta a complexidade dos exercícios com base no nível escolhido, 
   incluindo o tipo de lógica, a profundidade dos conceitos abordados, e o tamanho do desafio.

2. **Seleção da Vertical de Desenvolvimento:**  
   - **Opções:**  
     - **Frontend:** Foco em manipulação de DOM, eventos, CSS dinâmico, etc.  
     - **Backend:** Desafios envolvendo lógica de servidor, APIs, e banco de dados.  
     - **Full Stack:** Combinação de frontend e backend.  
     - **Mobile:** Exercícios relacionados a desenvolvimento híbrido ou focado em frameworks como React Native.  
   - Essa escolha direciona o tipo de problema gerado.



3. **Geração de Exercícios Personalizados:**  
   - A aplicação utiliza a API da OpenAI para criar exercícios adaptados às preferências do usuário.  
   - Cada exercício inclui:  
     - **Descrição:** Contextualizando o problema.  
     - **Objetivo:** O que o usuário precisa alcançar.  
     - **Dicas (Opcional):** Ajuda para usuários que estão com dificuldades.  
     - **Teste de Entrada/Saída (Opcional):** Definir inputs e outputs esperados para validar a solução.

4. **Interface de Apresentação do Exercício:**  
   - Exibição amigável do enunciado do exercício.
   - Opções para pedir ajuda (ex: gerar dicas automáticas ou exemplos de solução parciais).

---

### **Tecnologias e Ferramentas Sugeridas:**

- **Frontend:**  
  - React.js para construção da interface.  

- **Backend:**  
  - Node.js + Express para gerenciar requisições à API da OpenAI e fornecer exercícios gerados.  

- **API:**  
  - OpenAI API para geração dinâmica dos exercícios.  

---

### **Fluxo de Uso do Sistema:**

1. O usuário acessa o sistema e seleciona as preferências:  
   - Nível de dificuldade.  
   - Vertical desejada (frontend, backend, etc.).  

2. O sistema processa as entradas e faz uma requisição à API da OpenAI, fornecendo os parâmetros necessários para gerar o exercício.  

3. O exercício é apresentado na interface.

4. Após o envio da solução, o sistema pode:  
   - Oferecer a solução 
   - Oferecer dica para resolução do exercício
   - Oferecer a geração de outro exercício
